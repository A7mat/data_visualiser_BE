# Data Visualization Tool - Backend Service

Backend service to create visual representation for data records in the form of Graphs/Tables.


## Getting Started

Follow these steps to set up and run the Django project locally.

### Prerequisites
Make sure you have the following installed on your system:
- Python (>= 3.8)
- pip (Python package manager)

### Installation
**Clone the repository**
   ```sh
   git clone https://github.com/A7mat/data_visualiser_BE.git
   cd data_visualiser_BE
   ```

### Running the Development Server
Start the Django development server with:
```sh
python manage.py runserver
```

The application should now be accessible at `http://127.0.0.1:8000/`.


### Additional Commands
- Collect static files:
  ```sh
  python manage.py collectstatic
  ```
- Create a new app:
  ```sh
  python manage.py startapp <app_name>
  ```
